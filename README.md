# Vocaliscope
GUI for multi-channel signal manipulation and analysis in voice research based on Matlab.

## How to use
The app is available as compiled .exe and as .mlapp file.
When using the compiled exe, you need to have installed the [Matlab Runtime Engine](https://www.mathworks.com/products/compiler/matlab-runtime.html). The proper version corresponds to the Matlab Version used to compile the .exe, which is 2026a starting from Vocaliscope V5.0.
When a Matlab license is available, the .mlapp file can be used, which is (from experience) a bit more performant.

### Using the mlapp file structure
When you want to use this app via Matlab itself, you just need to download the "forCompiling" folder, which contains the exact structure ready to use in Matlab.
### Using the exe file
When using the the exe file, you need everything the exe file and any other folder there **EXCEPT** the "forCompiling" folder. For example, there is a folder which contains Praat scripts, which must be downloaded when you want to use the Praat functions inside this app.
