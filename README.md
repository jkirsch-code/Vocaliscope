# Vocaliscope
GUI for signal manipulation and analysis in voice research based on Matlab.

## How to use
The app is available as compiled .exe and as .mlapp file.
When using the compiled exe, you need to have installed the [Matlab Runtime engine]([https://pages.github.com/](https://mathworks.com/products/compiler/matlab-runtime.html)). The proper version corresponds to the Matlab Version used to compile the .exe, which is 2026a starting from Vocaliscope V5.0.
When a Matlab license is available, the .mlapp file can be used, which is from experience a bit more performant.
